Anything is an AI-powered app builder that turns natural-language prompts into working web and mobile applications, complete with a built-in PostgreSQL database, authentication, backend functions, custom domains, and 100+ third-party integrations. Its public REST API (v0) lets agents and developers programmatically create projects, request AI-generated changes, provision databases, manage secrets and domains, publish web apps, and submit mobile apps to the App Store and Play Store. Backed by Bessemer Venture Partners and Uncork Capital.

**Areas:** Company · Artificial Intelligence · App Builder · Low-Code · No-Code · Developer Tools · AI Agents · Mobile

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Anything: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
